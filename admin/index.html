Informations du site

À quoi sert cette zone ?

Elle permet de conserver dans Supabase de petites informations qui peuvent changer régulièrement sans modifier le code : téléphone public, e-mail, adresse, horaires de visite ou message pratique.

Une information n’est affichée automatiquement sur le site public que si une zone du site utilise la même clé technique.

Utilise une clé courte, sans espace. Si elle existe déjà, sa valeur sera mise à jour.
